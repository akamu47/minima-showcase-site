### 1. Minima (Main Protocol)
- **URL**: https://github.com/minima-global/Minima
- **Stars**: 137 | **Forks**: 148
- **License**: Apache-2.0
- **Latest Release**: v1.0.45 (Mar 28, 2025), 6 releases total
- **Languages**: JavaScript 82.1%, Java 12.6%, HTML 3.5%, CSS 1.8%
- **Description**: The Minima protocol Java libraries and application
- **Key Technical Details**:
  - Every user runs a full and complete node
  - UTXO model like Bitcoin
  - MMR Proof DB — users track only their own coins
  - Advanced scripting: covenants, state machine, MAST, quantum secure signatures, merkle proof checks
  - Default port: 9001, MDS (MiniDAPP System) port: 9003 (SSL)
  - Docker available: `minimaglobal/minima:latest`
  - Build with Gradle: `./gradlew clean build`
  - Private test-net support
